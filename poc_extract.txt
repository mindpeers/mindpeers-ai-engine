System Overview
This system is designed to provide mental health insights, predictions, and guidance using a hybrid architecture:
LLM → reasoning & explanation
ML → prediction
Deterministic features → signals
It supports:
Users
Therapists
Organizations
Core Problem: Cold Start
This is a very important product + ML problem called the Cold Start Problem.
It happens when:
A new user joins
Very little historical data exists
Many features in your dataset are missing
Your system must still produce useful insights, but it cannot rely on the full contextual dataset.
So you must design different intelligence levels based on data maturity.
The Problem
Your full dataset requires:
14 day windows
30 day baselines
7 day slopes
cohort percentiles
behavioral persistence
But a new user might have:
day 1: registration
day 3: first therapy session
day 5: mood entry
So features like:
mood_avg_14d
engagement_slope_7d
sleep_delta_30d
cannot be computed yet.
Solution: Multi-Stage Intelligence System
Instead of one system, you build three intelligence levels.
Stage 1 — Cold Start Intelligence (0-7 days)
Available data:
demographics
first assessments
initial therapy intake
first few mood entries
first sessions
Possible questions:
What are this user's initial mental health concerns?
What risk profile does this user belong to?
What therapy type might work best?
What baseline risk category does this user fall into?
Signals used:
age_band
gender
organization
initial clinical tests
therapist intake notes
Possible predictions:
initial risk category
recommended therapy intensity
likelihood of engagement
This is population-based inference, not personal trends.
Stage 2 — Early Behavior Intelligence (7-30 days)
Now you have early signals.
You can compute:
7 day slopes
engagement trends
early behavioral patterns
Possible questions:
Is the user engaging with therapy?
Is mood improving after therapy sessions?
Is engagement declining early?
Possible predictions:
early dropout risk
engagement decline risk
therapy response signals
But still limited because: baseline windows incomplete
Stage 3 — Full Contextual Intelligence (30+ days)
Now your full dataset becomes available.
You can compute:
baseline deltas
cohort percentiles
persistence features
multi-domain correlations
Now the system can answer:
Why is the user's mood declining?
Is sleep affecting mental health?
Is therapy effective?
What risk signals exist?
This is the full intelligence layer.
How to Handle Missing Features Technically
When features are missing, you should:
Use missing flags
Example:
sleep_delta_30d = null
sleep_delta_missing = 1
Models can learn from missingness.
Use cohort priors
Example:
If user has only 3 days data:
Use statistics from similar users:
same age
same therapy type
same organization
Use fallback models
Instead of one model:
You use model tiers.
Example:
Cold Start Model
Early User Model
Full Context Model
Each uses different features.

Decision Engine (Critical Component)
You need a Routing Layer.
Pseudocode
def route_query(query):
    intent = classify_intent(query)
    if intent in ["RISK_PREDICTION"]:
        use_ml = True
    else:
        use_ml = False
    features = fetch_features(intent)
    if use_ml:
        prediction = call_ml_model(features)
    else:
        prediction = None
    response = call_llm(query, features, prediction)
    return response

Execution Pseudocode
def handle_query(query, user_id):
    intent = classify_intent(query)
    config = INTENT_CONFIG["intents"][intent]
    features = fetch_features(user_id, config["features"])
    prediction = None
    if config.get("use_ml"):
        prediction = run_model(config["model"], features)
    prompt = build_prompt(
        template=config["llm_template"],
        query=query,
        features=features,
        prediction=prediction
    )
    return call_llm(prompt)
